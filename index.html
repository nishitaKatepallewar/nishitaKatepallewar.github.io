Core Features

Built for
game pipelines.

  • 01 Topology

    Finds n-gons, non-planar faces and intersecting meshes. Fixes most in one click.

  • 02 UV Validation

    Catches missing UV maps and broken lightmap UVs.

  • 03 Textures

    Flags missing images and wrong colour spaces.

  • 04 Transforms

    Catches unapplied scale, mirrored objects and off-centre pivots.

  • 05 Naming

    Flags default names, bad characters and missing prefixes like SM_.

→Every result saves as a JSON report.

Workflow

Four steps
to clean assets.

Step 01
Install

Add the .zip in Blender's preferences. No account needed.

Step 02
Select Assets

Select your meshes and open the Vexa tab (N).

Step 03
Check

Pick a target and click Check Assets.

Step 04
Fix & Export

Apply safe fixes in one click, then export.
